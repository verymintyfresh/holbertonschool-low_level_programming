# README

## What is this directory?
This directory contains files for the Malloc, Free project, as described below.

| File | Description |
| ---- | ----------- |
| main.h | Contains declarations of various functions for the project. |
| 0-create\_array.c | Creates an array and initialises it with a certain byte. |
| 1-strdup.c | Clones a string to a new location in memory. |
| 2-str\_concat.c | Creates a string from two existing strings. |
| 3-alloc\_grid.c | Creates a 2-dimensional array of integers. |
