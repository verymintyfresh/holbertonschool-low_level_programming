# README

## What is this directory?
This directory contains files for the Functions and nested loops project, as described below.

| File | Description |
| ---- | ----------- |
| main.h | Header file for the project |
| 0-putchar.c | Prints the string `_putchar`. |
| 1-alphabet.c | Contains a function which prints the alphabet in lowercase. |
| 2-print\_alphabet\_x10.c | Contains a function which prints the alphabet in lowercase, ten times. |
| 3-islower.c | Checks whether a number represents a lowercase ASCII character. | 
| 4-isalpha.c | Checks whether a number represents a letter in ASCII. |
| 5-sign.c | Prints the sign of a given number. |
| 6-abs.c | Calculates the absolute value of a number. |
| 7-print\_last\_digit.c | Returns and prints the last digit of a number. |
