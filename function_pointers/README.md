# README

## What is this directory?
This directory contains files for the Function Pointers project, as described below.

| File | Description |
| ---- | ----------- |
| function\_pointers.h | Contains declarations of various functions for the project. |
| 0-print\_name.c | Uses a given function pointer to print a name. |
| 1-array\_iterator.c | Performs an action on each element of an array. |
| 2-int\_index.c | Returns the first index of an array where a function is true. |
| 3-calc.h | Contains declarations of various functions and types for task 3. |
| 3-main.c | Main function for task 3. |
| 3-op\_functions.c | Defines functions for a calculator program (task 3). |
| 3-get\_op\_func.c | Returns a pointer to a function based on an operator. |
