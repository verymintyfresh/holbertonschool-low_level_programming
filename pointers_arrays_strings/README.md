# README

## What is this directory?
This directory contains files for the Pointers, Arrays and Strings project, as described below.

| File | Description |
| ---- | ----------- |
| main.h | Contains declarations of various functions for the project. |
| 0-reset\_to\_98.c | Changes a variable to 98 using a pointer. |
| 1-swap.c | Swaps two variables using pointers. |
| 2-strlen.c | Returns the length of a string. |
| 3-puts.c | Prints a string. |
| 4-print\_rev.c | Prints a string in reverse. |
| 5-rev\_string.c | Reverses a string in-place. |
| 6-puts2.c | Prints every other character of a string. |
| 7-puts\_half.c | Prints the second half of a string only. |
| 8-print\_array.c | Prints a number of variables from an array. |
| 9-strcpy.c | Copies a string into destination pointer. |
| 100-atoi.c | Finds a number in a string. |

It also contains files for the More Pointers, Arrays and Strings project:

| File | Description |
| ---- | ----------- |
| 0-strcat.c | Concatenates two strings. | 
| 1-strncat.c | Concatenates a string with a specified number of characters from a second string. |
| 2-strncpy.c | Copies a specified number of characters from a string into another. |
| 3-strcmp.c | Compares two strings. |
| 4-rev\_array.c | Reverses an array of integers in-place. |
| 5-string\_toupper.c | Converts a string to uppercase. | 
| 6-cap_string.c | Capitalises every word in a string. |
| 7-leet.c | Converts a string to 1337 73x7. |
