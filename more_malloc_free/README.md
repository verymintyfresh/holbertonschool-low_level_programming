# README

## What is this directory?
This directory contains files for the More Malloc, Free project, as described below.

| File | Description |
| ---- | ----------- |
| main.h | Contains declarations of various functions for the project. |
| 0-malloc\_checked.c | Allocates memory, but exits on failure. |
| 1-string\_nconcat.c | Concatenates a given number of bytes of a second string onto a first string. |
| 2-calloc.c | Allocates memory for an array. |
| 3-array\_range.c | Generates an array containing values between a specified minimum and maximum. |
| 100-realloc.c | Copies memory to a new block with a new size. |
