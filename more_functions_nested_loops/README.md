# README

## What is this directory?
This directory contains files for the More Functions, Nested Loops project, as described below.

| File | Description |
| ---- | ----------- |
| 0-isupper.c | Determines whether an integer represents an uppercase ASCII character. |
| 1-isdigit.c | Determines whether an integer represents an ASCII digit (0-9). |
| 2-mul.c | Multiplies two integers. |
| 3-print\_numbers.c | Prints numbers from 0 to 9. |
| 4-print\_most\_numbers.c | Prints most numbers from 0 to 9. |
| 5-more\_numbers.c | Prints even more numbers. |
| 6-print\_line.c | Prints a number of underscores. |
| 7-print\_diagonal.c | Prints a diagonal line. |
| 8-print\_square.c | Prints a square of hashes. |
| 9-fizz\_buzz.c | Does the Fizz Buzz test. |
| 10-print\_triangle.c | Prints a right-angled triangle. |
| 100-prime\_factor.c | Finds the largest prime factor of a particular number. |
| 101-print\_number.c | Prints a number using `_putchar`. |
