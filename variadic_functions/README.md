# README

## What is this directory?
This directory contains files for the Variadic Functions project, as described below.

| File | Description |
| ---- | ----------- |
| variadic\_functions.h | Contains declarations of various functions for the project. |
| 0-sum\_them\_all.c | Uses a given function pointer to print a name. |
| 1-print\_numbers.c | Prints a list of numbers with a given separator between them. 
| 2-print\_strings.c | As above, but with strings instead. |
| 3-print\_all.c | Prints a list of anything. |
