# README

## What is this directory?
This directory contains files for the Variables: if, else, while project, as described below.

| File | Description |
| ---- | ----------- |
| 0-positive\_or\_negative.c | Prints whether a number is positive, negative, or zero. |
| 1-last\_digit.c | Prints the last digit of a number and some information about it. |
| 2-print\_alphabet.c | Prints the alphabet in lowercase without using printf/puts etc. | 
| 3-print\_alphabets.c | As above, but also prints in uppercase. |
| 4-print\_alphabt.c | Prints the alphabet in lowercase as above but with no `q` or `e` character. |
| 5-print\_numbers.c | Prints all the digits of base 10 on one line. |
| 6-print\_numberz.c | As above, but using `putchar`. |
| 7-print\_tebahpla.c | Prints the alphabet in lowercase, in reverse. |
