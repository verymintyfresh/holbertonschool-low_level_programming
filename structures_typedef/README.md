# README

## What is this directory?
This directory contains files for the Structures, Typedef project, as described below.

| File | Description |
| ---- | ----------- |
| dog.h | Describes a dog. |
| 1-init\_dog.c | Initialises a variable of type `struct dog`. |
| 2-print\_dog.c | Prints information about a `struct dog`. |
| 4-new\_dog.c | Creates a new variable of type `dog_t` with given information. |
